使用说明与技术边界

真正离线的前提

此 HTML 是应用本体；模型与运行库在首次准备时从 Hugging Face、jsDelivr 或其备用源下载到 Firefox 的本机存储，不嵌入初始压缩包。准备完成后，页面的推理工作线程关闭网络访问，并重新从缓存加载模型进行检查。不调用浏览器的在线听写，也不调用云端聊天 API。系统朗读仅选择标记为本地的语音；Android 的具体语音引擎仍需安装中英文离线语音数据。

Android Firefox 的打开方式

麦克风、工作线程与 IndexedDB 必须在当前入口可用。HTTPS、localhost 或浏览器认可的本地文件上下文均需实测；Android 文件管理器交给浏览器的 content:// 链接不一定满足这些条件。页面会在下载大模型之前检查，并在权限不足时停止，不会冒充“已就绪”。单个 HTML 无法绕过浏览器权限，也无法自行建立 HTTPS 服务。

让 AI 决定，而不是堆规则

本地对话模型根据提示词提出停顿等待、神经语音检测阈值、最短发声和朗读语速；Silero 判断是否有人说话，Whisper 生成文字，Qwen 生成回答。模型输出无效时使用明确标记的备用值。采样率、张量维度、语音 API 的合法范围、缓存块大小、防卡死计时与移动端上下文上限仍是工程约束，不伪称由 AI 决定。回答尽量由模型的结束标记终止，没有固定对话时长或固定轮数。

怎样说话

看到“正在听”时直接说话，停顿后 AI 自动回应。为避免扬声器回声，本版采用轮流说话：识别、思考和朗读时暂停收音。长发言按识别模型的窗口分块。切换应用或锁屏可能被 Android 暂停；页面会在可检测时暂停并提示继续，不承诺后台运行。环境嘈杂、口音与小模型能力都会影响效果。

保存什么，保存到哪里

自动保存提示词、识别文字、AI 回答、时间与中断状态。结束后还会请求下载 TXT；是否弹出保存提示、是否成功写入下载目录，由 Firefox 决定。只有本机数据库事务完成后才显示“已保存”。未能转写的已接收语音片段暂存在本机历史中，可导出 WAV；普通成功识别的原始录音不长期保留。本机记录不加密，不上传；网站数据被删除后无法凭空恢复，重要记录请导出备份。长期对话超过上下文额度时，模型只读取最近的完整轮次，完整历史仍保存。

已知边界

此交付未经过 Android 17 + Firefox 真机端到端验收。浏览器内的单线程 CPU 推理可能较慢、耗电或超出设备内存；操作系统杀死页面时，也可能来不及保存正在录入且尚未交付到页面的声音。页面自检只证明当前环境的相关调用通过，不保证模型的识别或回答质量，也不能证明系统语音引擎在所有断网情形下都可靠。
